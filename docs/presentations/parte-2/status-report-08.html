  • ✓US-56 (Front): Navegación mobile táctil con categorías sticky y scroll-spy optimizado mediante IntersectionObserver calibrado (offset de 140px, detección precisa de extremos y liberación inmediata ante toque manual).   • ✓Calidad de Código React 19: Eliminadas llamadas síncronas a setState en efectos en CartBottomSheet, ModalPersonalizacion y OnboardingTour, logrando npm run lint con 0 errores.
