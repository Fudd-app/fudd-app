# Agentes de IA — material generado

Todo lo que producimos trabajando con agentes (Claude, Codex, Copilot, Gemini) y que vale la pena compartir con el equipo.

Las **reglas** para los agentes no viven acá: la fuente de verdad es [AGENTS.md](../../AGENTS.md). `CLAUDE.md`, `CODEX.md` y `.github/copilot-instructions.md` solo apuntan a ese archivo, porque cada herramienta los busca en esa ubicación.

| Carpeta | Qué contiene |
|---|---|
| `memory/` | Notas persistentes y feedback acumulado para los agentes. `MEMORY.md` es el índice. |
| `superpowers/plans/` | Planes de implementación generados antes de ejecutar un sprint o feature. |
| `superpowers/specs/` | Specs de diseño que respaldan esos planes. |

## Qué subir

- Planes, specs y decisiones que expliquen *por qué* se hizo algo y sirvan a otro integrante o agente.
- Memoria/feedback que deba aplicarse en todo el equipo, no solo en una máquina.

## Qué no subir

- Archivos de trabajo temporales (diffs de review, briefs/reportes intermedios por tarea, logs de sesión).
- Cualquier `.env`, token o credencial.
